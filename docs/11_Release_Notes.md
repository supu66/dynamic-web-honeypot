# Versioning Strategy

The project follows Semantic Versioning (SemVer):

```
MAJOR.MINOR.PATCH
```

Example:

```
v1.0.0
```

Where:

- **MAJOR** – Breaking changes or major milestones.
- **MINOR** – New features or significant improvements.
- **PATCH** – Bug fixes and minor updates.
