## Challenges

During the foundation phase, several implementation challenges were encountered:

- Learning the Git initialization and repository workflow.
- Understanding the difference between local and remote repositories.
- Resolving confusion caused by VS Code's Compact Folders feature.
- Designing a scalable folder structure before any application code existed.
- Balancing realistic company branding with ethical cybersecurity practices.

---

## Lessons Learned

Key lessons from the foundation phase include:

- Git does not track empty directories, making `.gitkeep` files necessary.
- Well-structured documentation significantly improves project planning.
- Defining architecture before implementation reduces future refactoring.
- Consistent branding strengthens the realism of the honeypot.
- Small, incremental improvements are easier to maintain than large, unplanned changes.

---

## Decisions Made

During the foundation phase, several key decisions were made to establish a strong and maintainable foundation for the project.

### Documentation-First Development

The project will prioritize planning and documentation before implementation. Major architectural, branding, and engineering decisions will be documented prior to writing application code.

### Fictional Corporate Identity

Aetheris Technologies was established as a completely fictional organization to provide a realistic enterprise environment while avoiding confusion with real-world companies.

### Technology Stack

The initial implementation will use:

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

Additional technologies will be introduced only when they provide clear value to the project.

### Architecture

The application will follow Flask's Application Factory Pattern and a modular architecture to improve maintainability, scalability, and separation of concerns.

### Versioning Strategy

The project will adopt Semantic Versioning (SemVer) to clearly communicate development milestones and release progress.
